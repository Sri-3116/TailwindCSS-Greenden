# 🌿 Greenden - Responsive Interior Plant Storefront

Greenden is a clean, modern, and highly responsive multi-page e-commerce storefront layout designed for a premium indoor plant retail boutique. The project features a fluid mobile-first architecture, clean component spacing, and micro-interactions optimized across multiple browser viewports.

## 🚀 Key Features

* **Multi-Page Navigation:** Includes three semantic, structurally independent pages (`index.html`, `product.html`, and `contact.html`) linked seamlessly via a sticky navigation header.
* **Mobile-First Responsiveness:** Built using flexbox configurations and multi-column grid layouts (`grid-cols-2 md:grid-cols-4`) that look great on smartphones, tablets, and wide monitors.
* **Interactive UI States:** Leverages smooth 2D transformations and scale card translations (`group-hover:scale-105 transition`) to improve visual feedback on hover.
* **Polished Tailwind Styling:** Implements professional card component spacing, explicit typography hierarchies, custom shadow distributions, and integrated inline vector icons.
* **Dedicated Support & Features:** Showcases key brand selling points including a large botanical assortment, 100% free and fast delivery tracking, and a 24/7 expert care helpline.

## 📁 Project Structure

```text
├── product.html        # Plant catalogue grid layout with real-time text filter bar
├── contact.html        # Dark-mode responsive customer service feedback form
└── images/             # Local optimized directory for high-res plant photography
```
